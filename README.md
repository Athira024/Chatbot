# College Enquiry Chatbot

The **College Enquiry Chatbot** is an intelligent web-based application developed to improve student services through automated conversations. It uses Deep Learning and Natural Language Processing (NLP) to provide real-time, interactive responses to user enquiries.

The chatbot helps students and visitors obtain information about college admissions, academic programs, campus facilities, and administrative procedures. It aims to improve accessibility, responsiveness, and the overall user experience by providing an interactive platform for college-related enquiries.

## Features

- **Interactive Chat Interface:** Provides a user-friendly interface for communicating with the chatbot.
- **Real-Time Responses:** Delivers interactive responses to user enquiries.
- **Admission Enquiries:** Provides information related to college admission procedures.
- **Academic Programs:** Helps users explore information about academic courses and programs.
- **Campus Facilities:** Provides information about available college facilities.
- **Administrative Information:** Assists users with common administrative enquiries.
- **NLP-Based Interaction:** Uses Natural Language Processing to understand and respond to user queries.
- **Automated Student Support:** Reduces the need for manual responses to frequently asked college-related questions.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Core Concepts:** Deep Learning, Natural Language Processing (NLP)

## Tools

- Visual Studio Code
- Python
- Django
- Git and GitHub

## Project Purpose

This project was developed to explore the application of Deep Learning and Natural Language Processing in web-based chatbot systems. It provides practical experience in Python, Django, frontend development, and building interactive automated student support systems.
